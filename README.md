🚀 Project Summary
This project focuses on building a fault-tolerant ISP network for ConnectSphere. The design links three cities (City A, City B, and City C) in a triangular topology using Cisco routers. Static routing is configured with floating backup routes so that if the primary connection between City A and City B goes down, traffic automatically reroutes through City C within 60 seconds, ensuring minimal downtime.
